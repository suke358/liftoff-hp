プライバシーポリシー

Lift-Off（防府のお店のホームページ制作・WEB担当者代行。以下「当方」）は、お客さまからお預かりする情報を、次のとおり大切に取り扱います。

1. お預かりする情報

  • お問い合わせフォーム・LINE・お電話・メールでいただく、お名前・ご連絡先・ご相談の内容
  • ご契約のお店の、ホームページや Google ビジネスプロフィールなどの管理に必要なアカウントの情報

2. 使い道

お預かりした情報は、次のことにだけ使います。

  • お問い合わせへのお返事
  • ホームページの制作と更新
  • お見積もり・ご請求
  • ご契約のお店への毎月のご報告

3. Google のサービスから受け取る情報

ご契約のお店のご許可をいただいた場合に、そのお店の Google ビジネスプロフィールの情報（表示された回数などの数字・営業時間）を、Google のしくみ（API）を通して受け取ります。

  • 受け取った情報は、そのお店のホームページの表示と、そのお店への毎月のご報告にだけ使います。
  • お店にご許可いただいた範囲の外では使いません。ほかの目的に使うこと、売ること、第三者に渡すことはしません。

Google の API から受け取った情報の使い方と他への受け渡しは、Google API Services User Data Policy（Limited Use の決まりを含む）に沿います。

4. 第三者への提供と、外のサービスの利用

お預かりした情報は、法令にもとづく場合を除き、ご本人の同意なく第三者に渡しません。

お問い合わせの受け付けやホームページの公開のために、外のサービス（Formspree・Cloudflare・Google など）を使っています。これらのサービスを通る情報は、それぞれのサービスの決まりにしたがって取り扱われます。

5. 管理

お預かりした情報は適切に管理し、第三者には渡しません。お客さまとのやり取りのメッセージに、パスワードなどを書くこともしません。

6. 消してほしいとき・お問い合わせ

お預かりしている情報を見たい・直したい・消してほしい、また、Google の情報の受け取りをやめてほしいときは、下の窓口までご連絡ください。ご本人であることを確かめたうえで対応します。
