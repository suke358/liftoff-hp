# 追加の部品（make_site.py）説明書　2026/10/30版

**要点（3行）**
- make_site.py に、9つの部品を足した（元の部品：belt・compare・calc・cases・form・shop）。コードは `tools/parts_extra.py` 1つに分けてある（make_site.py には呼ぶ所だけ）
- どれも設定（parts）に中身があるときだけ出る。空なら何も出ない。**写真がなくても信頼が出る部品**（実績・選ばれる理由・対応エリア・営業時間・お知らせ）が中心
- 見本は `templates/site_sample_extra.json`（架空の松葉造園に全部入り）。作って見る：`python3 tools/make_site.py tools/templates/site_sample_extra.json 作るフォルダ`

## 部品の一覧
| 部品 | 何が出るか | 写真 | 向いているお店 | 注意 |
|---|---|---|---|---|
| notice | 最上部の細い帯（1行）。臨時休業・繁忙期 | 不要 | 全部 | 長い文は切れる（1行固定） |
| credentials | 実績・資格の数字の帯（2〜4個）。例「3位／造園の全国大会」 | 不要 | 造園・工務店・士業・教室 | 事実だけ。大会名・年はお店に確かめる |
| strengths | 選ばれる理由（番号カード2〜4） | 不要 | 全部 | すでにサイトにある事実だけ。自慢や断定は書かない |
| news | お知らせの日付つき一覧（3件＋「これまでの」） | 不要 | 全部（月の更新の成果が見える） | 新しい順に並べて書く |
| voices | お客様の声（最大6） | 不要 | 全部 | **実在・了承ずみだけ**。各項目に `"consent": true`。本物のお店で無いと作れない（❌ で止まる） |
| hours | 営業時間の表＋「いま営業中／時間外（次は〜）」 | 不要 | サロン・飲食・店舗 | schedule は mon〜sun。休みは ""。複数時間帯は "09:00-12:00,13:00-18:00"。臨時休業は holidays に日付 |
| areas | 対応エリアの札（main＝色つき・also） | 不要 | 出張系（造園・清掃・リフォーム） | 行けない所を載せない。分からない市町は書かない |
| video | 動画（押したときだけ YouTube を読み込む） | 動画ID | 施工・店内の雰囲気 | 動画IDはお店の動画だけ。字幕・権利を確かめる |
| lightbox | 帯・施工例・メニューの写真を押すと拡大 | あれば | 写真があるお店 | 設定は `true` だけ。見比べつまみの写真は対象外 |

## 設定の書き方（全部は site_sample_extra.json を見る）
```json
"parts": {
  "credentials": {"items": [{"value": "3位", "label": "造園の全国大会", "note": "（大会名・年）"}]},
  "strengths":   {"title": "選ばれる理由", "items": [{"title": "木1本から", "text": "…"}]},
  "news":        {"items": [{"date": "2026.10.30", "tag": "お知らせ", "text": "…"}], "limit": 3},
  "hours":       {"title": "受付時間", "open_word": "受付中", "schedule": {"mon": "08:00-17:00", "sun": ""}, "holidays": ["2026-12-31"]},
  "areas":       {"main": ["防府市"], "also": ["山口市"], "note": "…"},
  "voices":      {"items": [{"text": "…", "who": "〇〇市・60代", "consent": true}]},
  "video":       {"youtube": "動画ID", "title": "作業の様子"},
  "notice":      {"text": "年末は混み合います", "url": "#reserve"},
  "lightbox":    true
}
```
- 並び順は決まっている（hero → credentials → ごあいさつ → strengths → 帯 → メニュー → 商品 → 料金の目安 → 施工例 → 前後 → video → voices → 流れ → news → 相談 → hours → areas → 店舗情報 → FAQ）
- 上の案内（ヘッダー）には voices・news を出さない（長くなって崩れるため）。目次（トップの札）には出る

## お店の種類ごとのおすすめの組み合わせ
| 種類 | 組み合わせ |
|---|---|
| 造園・外構・リフォーム | credentials＋strengths＋belt＋cases＋compare＋areas＋voices＋news＋lightbox |
| サロン（予約あり） | strengths＋hours＋voices＋news＋form |
| 飲食・物販 | hours＋news＋shop／belt＋lightbox＋video |
| 写真も連絡先もまだないとき（試作） | credentials＋strengths＋areas（事実だけで形になる） |

## 守ること（このセットで足したルール）
- **分からない情報は書かない**。数字（創業年・件数）・資格・大会名は、お店に確かめてから
- **お客様の声は作らない・無断で載せない**。`consent: true` がないと、本物のお店では作れない
- 本物の動画IDだけ。サンプルの動画IDは見本用
- 古いスマホ対策：JS は var・function だけ／gap・aspect-ratio・inset・svh は使わない／動きを減らす設定では止める（check_site の「古いスマホ」は ✅ のまま）

## 見つけた問題と直したこと
- ヘッダーの案内が6つ以上になると、文字が縦に割れた → 案内は nowrap にし、voices・news は案内から外した（make_site.py の `.nav a` と nav の1行）
- 実績の帯が3つだとスマホで1つだけ余った → 最後の1つを2列ぶんにした
